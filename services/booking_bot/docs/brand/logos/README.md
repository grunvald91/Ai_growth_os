# Logos

- `servgo-logo.svg` — основной горизонтальный логотип для светлого фона: знак и словесный знак, «Serv» `brand-navy` (#0d1b2a), «Go» `brand-blue` (#2f5beb).
- `servgo-logo-on-dark.svg` — для тёмного фона: чернила белые, «Go» #7fa0ff (как в компоненте Logo с `light`).
- `servgo-mark.svg` — только знак (календарь с пером): фавикон, иконка приложения, подпись «Работает на ServGo».

Словесный знак набран текстом Onest 800; там, где шрифт не загружен, используйте знак и название рядом обычным текстом. Поле вокруг логотипа — не меньше высоты зубца календаря (≈ 1/5 высоты знака).
