# promo.servgo.ru — нишевые лендинги

**Дата:** 2026-05-31
**Автор:** Артур + Claude
**Статус:** Дизайн утверждён, готов к имплементации (пилот — 3 ниши)

## Контекст

Текущий лендинг `promo.servgo.ru` — обобщённый, единый шаблон Jinja `webapp/templates/landing.html` (288 строк), отдаётся приложением booking_bot на `127.0.0.1:8080` через Nginx (`/etc/nginx/sites-available/servgo-promo`). Боли и сценарии не привязаны к конкретной нише — посетитель из шиномонтажа, психолог и парикмахер видят одно и то же.

**Гипотеза.** Если на странице сразу видна боль конкретного бизнеса («звонки сыплются в субботу, перезванивать некогда»), CTR в Telegram-бот и конверсия в заявку вырастут в 2–3 раза по сравнению с обзорной страницей.

## Цель

Запустить нишевые версии лендинга по подпутям `promo.servgo.ru/<slug>` с минимальной инфраструктурной нагрузкой, провалидировать гипотезу на 3 пилотных нишах за 2 недели, и при успехе масштабировать на остальные ниши по конвейеру.

## 1. Архитектура (URL и шаблонизация)

### URL-схема

Выбрано: **подпути** `promo.servgo.ru/<slug>`.

Отвергнуты:
- Поддомены (`shinomontazh.servgo.ru`) — каждый требует отдельного certbot и nginx-server, медленно масштабируется.
- Query-параметры (`?niche=...`) — хуже SEO, не воспринимается как «своя страница».

Главная `/` остаётся обзорной (текущий `landing.html`) — работает как «зонтик».

### Файловая структура

```
webapp/templates/landing/
  _base.html          # шапка, футер, общая разметка
  niche.html          # extends _base, рендерит блоки из конфига

webapp/niches/
  _shared.yaml        # цены ServGo, общие фичи, общий FAQ
  beauty.yaml
  shinomontazh.yaml
  psy.yaml
  ...

webapp/routes/promo.py
  GET /              → текущий landing.html (обзорный)
  GET /<slug>        → niche.html (404 если slug не в реестре)
```

Добавление новой ниши = один YAML + опционально 6–8 SVG-иконок и hero-картинка. Без правки HTML и Python.

### SEO

В YAML каждой ниши: `title`, `meta_description`, `h1`, `og_image`, `canonical`. Hreflang не нужен — все на ru.

## 2. Каталог ниш и пилот

### Полный каталог

| Группа | Ниши |
|---|---|
| Красота | салоны, маникюр-педикюр, барбершопы, бровисты/визажисты, косметология, массаж/SPA |
| Здоровье и тело | психологи, логопеды, остеопаты, фитнес-тренеры, йога/пилатес-студии |
| Авто | шиномонтаж, автомойки, детейлинг, СТО |
| Аренда времени/места | бани/сауны, аренда залов, фотостудии, переговорки |
| Образование | репетиторы, автошколы, музыкальные педагоги, детские студии |
| Услуги дома | клининг, мастер на час, выездной грумер |

### Критерии приоритета

1. Уже есть кейс в ServGo (показываем живой бизнес).
2. Острая боль от переписок в чатах.
3. Объём рынка в Сочи и спроса в поиске.
4. Чёткость болей в отзывах конкурентов.

### Пилот — 3 ниши

| Slug | Ниша | Почему |
|---|---|---|
| `beauty` | Салоны красоты и маникюр | Массовый рынок, ServGo проектировался под них, кейсы есть, тяжёлые конкуренты (yclients/dikidi) |
| `shinomontazh` | Шиномонтаж и автосервис | Сезонные пики, классические боли «не дозвониться» и «приехал — очередь», мало нормальных онлайн-записей |
| `psy` | Психологи и частные специалисты | Растущий спрос, критична предоплата (no-show болит сильно), активно покупают сайты |

Три ниши закрывают три архетипа: массовый сервис → срочная услуга → премиальный специалист.

Волна 2 (по итогам пилота): бани/сауны, аренда залов, репетиторы.

## 3. Анатомия нишевой страницы

Что меняется между нишами vs что фиксировано.

| Блок | Общее | Нишевое |
|---|---|---|
| `<title>` / meta | — | title, description, og_image |
| Шапка | бренд, навигация, CTA «Открыть бот» | — |
| **Hero** | лого, форма CTA | h1, eyebrow, hero-stage (расписание/чип-карта/слоты — содержимое под услуги ниши) |
| Signal-strip (4 карточки) | 2 общие | 2 нишевые |
| **Боли владельца** (новый блок) | — | 4–5 болей под нишу + как ServGo их решает |
| Owners / возможности | заголовок, фичи | переформулировка под роль (мастер → автослесарь → терапевт) |
| Clients (путь из 4 шагов) | структура | подписи шагов |
| Compare | колонки и принцип | конкуренты ниши (для красоты — yclients/dikidi, для авто — autodoc/carbook, для психологов — yasno/alter) |
| Capability-grid | 12 фич | 2–3 подсвечены как «критично для вас» |
| Pricing | полностью | — |
| Launch | полностью | — |
| **FAQ нишевый** (новый блок) | — | 5–6 вопросов из возражений ниши |
| Final CTA + форма | полностью | placeholder в textarea |

### Источники болей

- Отзывы конкурентов на 2ГИС и Яндекс.Картах (1–3 звезды).
- Профильные Telegram-чаты владельцев.
- Вопросы из директа существующих клиентов booking_bot.
- Поисковые подсказки Wordstat по `{ниша} запись онлайн`.

### Шаблон боли

Одна фраза с конкретикой («звонки сыплются в субботу, перезванивать некогда — клиент ушёл к соседям») → одна строка как ServGo закрывает («запись 24/7 в Telegram, перезванивать не нужно»).

### Визуал

Для пилота — SVG-иконки услуг ниши + одна нейтральная фотография на hero (Unsplash/Pexels по лицензии). Фотосессии после валидации гипотезы.

## 4. Производственный конвейер одной ниши

Цель — нишевая страница за 1 рабочий день (после готовой инфраструктуры).

| # | Шаг | Кто | Время | Результат |
|---|---|---|---|---|
| 1 | Ресёрч ниши | `document-specialist` (web) | 30–45 мин | `docs/niches/<slug>-research.md`: 10 болей с цитатами, 5 конкурентов, топ услуг, возражения |
| 2 | Отбор формулировок | Артур + ИИ | 30 мин | Финальные 5 болей и 5 FAQ |
| 3 | Копирайт | `writer` агент по тон-оф-войс | 30 мин | h1, eyebrow, шаги клиента, compare-таблица |
| 4 | Заполнение YAML | вручную или генерацией | 10–20 мин | `niches/<slug>.yaml` |
| 5 | Визуал | подбор SVG + 1 фото | 20 мин | `/static/niche/<slug>/` |
| 6 | Релиз | Артур | 30 мин | Деплой, проверка мобильной вёрстки |

### Где используем агентов
- `oh-my-claudecode:document-specialist` — внешний ресёрч.
- `oh-my-claudecode:writer` — копирайт.
- `oh-my-claudecode:designer` — визуальная ревизия перед релизом.

Для пилота ресёрч 3 ниш запускается параллельно.

### Тон-оф-войс

Сохраняем текущий — мягкий, наблюдательный («ServGo превращает переписки в аккуратное расписание»). Без давления и инфоцыганщины. Боли подаём как наблюдения, не как угрозы.

### Definition of Done

- [ ] YAML валиден, страница рендерится без 500
- [ ] Все CTA-кнопки ведут на рабочие ссылки
- [ ] H1 содержит ключ ниши («запись онлайн для шиномонтажа»)
- [ ] Description ≤ 160 символов
- [ ] Мобильная вёрстка проверена на 360px
- [ ] OG-картинка отдаётся (превью в Telegram при репосте)
- [ ] UTM-метка на ссылках в бот
- [ ] Заявка из формы доходит в @mypersonalcc_bot
- [ ] Lighthouse mobile ≥ 90

## 5. Трафик, аналитика, метрики

### Источники трафика

| Источник | Что отдаём | Приоритет в пилоте |
|---|---|---|
| Холодные сообщения владельцам | прямая ссылка | все 3 |
| Авито (объявления услуг) | UTM-ссылка + QR | beauty, shinomontazh |
| 2ГИС / Яндекс Бизнес | ссылка в «сайт» | все |
| Reels/Shorts «как клиент записывается» | описание + ссылка | beauty, psy |
| Партнёры (поставщики, аренда) | QR-баннер | beauty, shinomontazh |
| Поиск (SEO) | органика 3+ месяца | не для пилота |

### Аналитика

- **На странице:** Plausible или Umami (без cookies, без баннера). События: `page_view`, `cta_telegram_click`, `cta_form_open`, `form_submit_success`. Один js-скрипт в `_base.html`.
- **UTM-схема:** `?utm_source={avito|cold|2gis|reels}&utm_medium=niche&utm_campaign={slug}`. Сохраняем в форме заявки рядом с именем/телефоном.
- **Сквозная воронка:** показ → клик в Telegram → подключение. В Google Sheets (1 строка = 1 заявка с UTM), без оверинженеринга.

### Метрики пилота (за 14 дней)

| Метрика | Цель |
|---|---|
| Уник. посетителей на нишевую страницу | ≥ 100 |
| CTR в Telegram-бот | ≥ 8% (vs ~3% на обзорной) |
| Конверсия в заявку | ≥ 2% |
| Стоимость заявки (при платном трафике) | ≤ 500 ₽ |

**Критерий перехода в волну 2:** 2 из 3 пилотных ниш бьют цели → масштабируем по конвейеру. Если только 1 — разбираем почему остальные не выстрелили.
