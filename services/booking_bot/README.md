# 🤖 Telegram Бот для Онлайн Записи

Универсальный бот для онлайн-записи клиентов в различные типы бизнесов: салоны красоты, автосервисы, психологи, шиномонтажи и другие.

## 📋 Возможности

### Для клиентов:
- 📅 Запись на услуги через удобный интерфейс
- 📋 Просмотр своих записей
- 🔔 Автоматические напоминания за день до визита
- 📱 Сохранение контактной информации

### Для владельцев бизнеса:
- 🏢 Управление несколькими бизнесами
- ➕ Добавление услуг и их настройка
- 👥 Управление сотрудниками/мастерами
- 📊 Просмотр всех записей
- ⚙️ Настройка рабочего времени и цен

## 🛠 Технологии

- **Python 3.10+**
- **aiogram 3.4** - фреймворк для Telegram ботов
- **PostgreSQL** - база данных
- **SQLAlchemy 2.0** - ORM для работы с БД
- **asyncpg** - асинхронный драйвер PostgreSQL
- **APScheduler** - планировщик задач для уведомлений

## 🚀 Установка и запуск

### 1. Клонирование проекта

```bash
cd booking_bot
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/MacOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка PostgreSQL

Установите PostgreSQL и создайте базу данных:

```sql
CREATE DATABASE booking_bot;
CREATE USER bot_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE booking_bot TO bot_user;
```

### 5. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Получите токен у @BotFather в Telegram
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Настройки PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=booking_bot
DB_USER=bot_user
DB_PASSWORD=your_password

# Часовой пояс
TIMEZONE=Europe/Moscow

# ID администраторов (можно узнать через @userinfobot)
ADMIN_IDS=123456789,987654321
```

### 6. Создание бота в Telegram

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен в `.env` файл

### 7. Запуск бота

```bash
python -m bot.main
```

Или:

```bash
cd bot
python main.py
```

Вы должны увидеть:

```
INFO - Запуск бота...
INFO - Инициализация базы данных...
INFO - База данных готова
INFO - Планировщик уведомлений запущен
INFO - Бот запущен и готов к работе!
```

## 📖 Использование

### Для клиентов:

1. Найдите бота в Telegram и нажмите `/start`
2. Нажмите "📅 Записаться"
3. Выберите заведение
4. Выберите услугу
5. Выберите мастера
6. Выберите дату и время
7. Подтвердите запись

### Для владельцев бизнеса:

1. Запустите бота командой `/start`
2. Нажмите "➕ Добавить бизнес" и следуйте инструкциям
3. Добавьте услуги через "➕ Добавить услугу"
4. Добавьте сотрудников через "👥 Добавить сотрудника"
5. Просматривайте записи через "📊 Записи"

## 🗃 База данных

### Основные таблицы:

- **users** - пользователи (клиенты и владельцы)
- **businesses** - бизнесы
- **services** - услуги
- **employees** - сотрудники
- **bookings** - записи

### Диаграмма связей:

```
User (1) ----< (N) Business
Business (1) ----< (N) Service
Business (1) ----< (N) Employee
User (1) ----< (N) Booking
Service (1) ----< (N) Booking
Employee (1) ----< (N) Booking
Business (1) ----< (N) Booking
```

## 🔔 Система уведомлений
