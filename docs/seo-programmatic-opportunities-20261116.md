# Programmatic SEO: карта посадочных страниц (пилот, 2026-11-16)

## Назначение

Внутри **существующего** SEO-завода появляется отдельная карта предложений
посадочных страниц под товары, услуги, устройства и подтверждённую географию.
Статьи в блоге продолжают работать по прежнему пайплайну.

**Пилот не публикует страницы.** Записи вида `/solutions/...` — предлагаемые
адреса, не маршруты production-сайта. Не включать их в `sitemap.xml`, не
создавать на них ссылки с клиентского сайта и не считать их индексированными.

## Откуда берутся данные

1. Стандартный сбор подсказок Google/Яндекса и семантическое ядро выбранной
   компании: только имеющиеся коммерческие/транзакционные запросы.
2. Собственный `products/<company-slug>/company-profile.json` выбранной
   компании: предложение может быть помечено подтверждённым **только** при
   `release_status=live|limited` и заполненном `evidence_refs`.
3. `identity.service_geography` — допустимая заявленная география.
   Она сама по себе **не** даёт права публиковать множество страниц для городов.

Система не оценивает частотность запросов, не придумывает цены, рейтинг
или прогноз трафика. Один прогон сохраняет не более 24 **новых или
изменившихся** кандидатов. Повторы из более ранних запусков той же компании
не создаются заново; если доказательства продукта меняются, кандидат
переоценивается и получает новую версию. Типичные перестановки слов,
дефисы и «цена/стоимость» сравниваются по лексическому поисковому намерению;
полноценное семантическое определение синонимов не заявлено.

## Логика и ограничения

- **review**: предложение сопоставлено с подтверждённым действующим продуктом;
  всё равно нужен уникальный контент, реальная польза страницы и проверка
  публикации редактором.
- **blocked / offer_evidence_required**: соответствующий действующий продукт
  не подтверждён. Нужно уточнить профиль, а не придумывать оффер.
- **blocked / local_value_required**: обнаружен заявленный региoн,
  но отдельная региональная страница требует реальных локальных фактов,
  отличающихся услуг или другой самостоятельной ценности.
- **blocked / unverified_geography**: в запросе есть географический признак,
  но компания не объявила этот регион. Эвристика намеренно консервативна,
  она не заменяет справочник всех мировых населённых пунктов.
- **blocked / device_evidence_required**: устройство найдено в запросе,
  но для выбранного оффера нет отдельного доказательства совместимости.
  Для этого в `ServiceOffer` можно заполнить
  `supported_devices_evidence: {"iphone": "ref-to-confirmed-guide"}`.
  Общий `evidence_refs` оффера для совместимости недостаточен.
  Эта запись разрешает лишь ручную проверку, не автоматическую публикацию.
- **blocked / already_covered**: по запросу уже существует активная/готовая
  SEO-статья; нельзя без анализа создавать конкурирующую страницу.
- Тип «устройство» отображается только по явно присутствующему в запросе
  названию устройства. Безопасность не подменяется догадкой о поддержке.
- Отсутствие структурированного профиля блокирует подтверждение продукта,
  но не скрывает источниковые предложения от владельца.

Черновики хранятся как `seo_landing_opportunities` (company + run).
Для повторного запуска того же задания запись переиспользуется.
Для новых запусков хранятся только новые или изменённые предложения;
исторические версии не теряются и имеют стабильный предлагаемый URL
с хеш-суффиксом, предотвращающим коллизии усечённых названий.
Статистика и список доступны в штатной панели SEO-завода и в сводке
запуска; другим компаниям данные не раскрываются.

## Что остаётся до публикации посадочных страниц

1. Добавить в Studio редактор кандидатов: привязать запрос к
   подтверждённому товару/услуге, указать независимую ценность страницы,
   проверяемые факты, CTA и целевой канонический маршрут.
2. Реализовать подходящий шаблон для фактического сайта компании и
   публикацию через его существующий согласованный механизм.
3. После проверки URL/HTML/canonical, sitemap, отсутствия дублей,
   ссылок и индивидуальных ограничений — разрешить выпуск.
4. Подключить Search Console / Яндекс Вебмастер и реальные события
   продаж для оценки: индексируется ли страница, есть ли показы,
   клики и полезные конверсии.

**Нет утверждения**, что большее число URL само по себе улучшает ранжирование.
