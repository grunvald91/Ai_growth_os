# Анализ рынка: Wordstat API v2

Модуль создан на основе ветки PR #127 «Бизнес-разведка». Экран: /market-research, API: /market-research/analyze, статус: /market-research/status.

## Подключение

1. Создать каталог Yandex Cloud и включить оплату Search API.
2. Создать сервисный аккаунт и предоставить search-api.webSearch.user.
3. Получить API-ключ для Search API и Folder ID.
4. На сервере добавить WORDSTAT_API_KEY и WORDSTAT_FOLDER_ID в закрытый .env (не в git). WORDSTAT_DAILY_LIMIT=40.
5. Деплоить после проверки тестов и корректности owner gateway. API в стандартном production Compose слушает 127.0.0.1:8091.

## Реализовано

- GetTop: частотность за последние 30 дней, связанные поисковые фразы.
- GetDynamics (опционально): месячная история за 12 полностью завершённых месяцев.
- Предустановленные регионы: Россия 225, Москва 213, Санкт-Петербург 2, Сочи 239.
- Жёстко задан только официальный HTTPS host Яндекса; ключ передаётся в заголовке Authorization: Api-Key.
- Дневной лимит платных запросов с транзакцией SQLite BEGIN IMMEDIATE и 12-часовой кэш на общем постоянном томе company_products/.wordstat.
- Один новый анализ: максимум один вызов, с помесячной динамикой — максимум два. При сетевой ошибке резерв сохраняется, чтобы предотвратить неограниченные попытки.
- Визуальный интерфейс в общем shell Growth Studio. Результаты отображаются через textContent, без HTML из стороннего API.
- Нет вызовов LLM, публикаций и автоматических платных фоновых задач.
- Тесты с MockTransport без реальных расходов.

## Ограничения

- Отправка запросов без ключа и Folder ID отключена.
- Защитой веб-страницы служит существующий приватный gateway и loopback bind; нельзя открывать route публично без аутентификации.
- Дневной лимит работает для этого экземпляра общего SQLite-хранилища; не ограничивает другие приложения, платные сервисы и ключи Yandex Cloud. Используйте также лимиты и уведомления биллинга.
- Частотность не измеряет число покупателей, готовность платить, конверсию, цены, незанятость ниши или рыночную долю.
- Сравнение конкурентов в Бизнес-разведке — отдельный workflow. Автоматическое объединение данных Wordstat и конкурентных источников требует дальнейшей разработки.
- Кэш живёт 12 часов; успешные запросы повторно не расходуют наш лимит до истечения срока.
- До доступа к облаку нет проверенной live-интеграции; код требует smoke test на сервере.
