# ServGo Mail V3 — нижнее управление и массовый ИИ-поиск

Дата: 2026-11-02. Рабочая ветка: `feature/mail-v3-bottom-ai-search-20261102`.

## Пользовательская модель

Три **основных** раздела для мобильных и десктопных экранов: «Поиск», «Рассылки», «Письма». Нижняя навигация унифицирована между двумя существующими защищёнными HTML-кабинетами. Отдельной основной вкладки «Контакты» нет: адресаты — часть рассылки, существующий список адресатов остаётся доступным из «Писем → Папки».

Нижняя зона содержит действия текущего раздела: в «Поиске» — запуск массового поиска, подбор ниш с ИИ, добавление подходящих адресатов и остановку; в «Рассылках» — создание, настройки отправки, действия кампании; в «Письмах» — новое письмо, папки и второстепенные действия. Настройки и остальные кнопки — в раскрываемых нижних меню. Основные данные и результаты сверху, без отдельных шапок с кнопками.

## Реальные возможности

Существующая фоновая задача `/api/company-search` ищет организации в 2ГИС и публичных сайтах по нише/городу, извлекает контакты и передаёт данные ИИ для индивидуальной оценки соответствия. Пользователь может указать количество компаний с email; поиск не ограничен одной компанией. Выбор рассылки позволяет перенести **подходящие адреса с email**, имеющиеся на момент импорта. Кнопка импорта доступна только для редактируемой рассылки.

ИИ **не отправляет** писем в момент поиска. Создание черновиков, их проверка, запуск и автоматическая отправка остаются отдельными действиями с прежними API и условиями. Подтверждение согласия и соблюдение правил рекламной почты сохраняются.

## Безопасность изменений

- Нет новых API, фоновых воркеров, почтовых запросов, доступов и секретов.
- Сохранены существующие `id` управления и API endpoint.
- Адаптация для `/api/owner-mail/workspace` продолжает использовать прежнее переписывание ссылок.
- Тема Light/Dark/System использует действующие ServGo Air токены.
- Не сливать без ручной проверки на 320/375/768/1280 px, теста авторизации, реальных статусов поиска и кликабельности нижней панели.
- Никаких реальных SMTP/IMAP массовых отправок ради тестирования, действий развёртывания и автоматических перезапусков.
