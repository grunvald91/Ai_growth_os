# ServGo AI Chat — первые три специалиста

Чаты — это серверные профили внутри существующего `/studio/chat`; отдельный агентный процесс не создаётся.

- `business_consultant`: диагностика, проверка идей, экономика услуги, решение по найму.
- `marketer`: позиционирование, каналы, воронка, маркетинговые планы и эксперименты.
- `smm_specialist`: контент по площадкам, видео, комментарии и аналитика.

## Безопасность и архитектура
- Идентификатор выбирается из фиксированного списка; через API нельзя передать произвольный system prompt.
- Роль записывается в беседе и не меняется при смене модели или повторном входе. Новый специалист — новый диалог.
- Контекст компании подгружается только через существующую проверку прав на компанию. Новых прав на Growth/BookingBot/Mail не появляется.
- В текущей реализации профиль действует на текстовые ответы. Режим генерации изображений остаётся исходным, без скрытой подмены промпта.
- Исходные большие методики не загружаются целиком: короткие ServGo-инструкции уже содержат выборочный набор приёмов. Интеграции с исполнением действий пока нет.
- При деплое необходима миграция Alembic `0017`; старые беседы остаются без роли (`null`).
