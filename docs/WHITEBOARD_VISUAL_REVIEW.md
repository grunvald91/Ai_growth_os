# Один визуальный критик и переделка рисунков без новой озвучки

## Поведение

Критик — подчинённая роль, а не автор ролика. После получения трёх рисунков
один vision-запрос рассматривает все сцены относительно исходного сценария.
Проверяются механика, расположение и ориентация деталей, соответствие репликам,
геометрия, читаемость текста и обрезанные элементы. Простота диаграммы сама по
себе не считается дефектом. Отмечаются видимое свидетельство, минимальная
правка, серьёзность и уверенность.

Основной автор одним запросом принимает или отклоняет каждое замечание
с объяснением. Только принятые blocking/major замечания с высокой уверенностью
могут вызвать перерисовку. Minor, style и uncertain программно запрещены
к платному исправлению. Если нет существенных замечаний, лишний вызов автора
и перерисовки пропускаются. Максимум одна перерисовка каждой выбранной сцены.
После неё второго прохода критика нет. Повторной генерации при ошибке нет.
Изменять тему, сценарий, подписи, голос или текст озвучки через решение критика
невозможно: схема решения содержит только ID замечаний, accept и reason.

В профиле Gemini критик использует Qwen3 VL 30B, основной автор — модель
сценария, новые изображения и перерисовки — Gemini 3.1 Flash Image через ClaudeHub. Это отдельные роли; критик использует
тот же проверенный vision model ID, что и разметчик, с другим контрактом.
Требования к первоначальным рисункам уточнены: ровные линии, ясные силуэты,
корректные пропорции и физические связи. Общее окружение/ключи не меняются.

## Озвучка и визуальная переделка

На странице готового видео добавлена кнопка «Переделать рисунки, сохранить
озвучку». Она создаёт отдельный запрос на визуальную правку, ожидающий
подтверждения. Исходное задание не меняется. Проверяются одобрение исходника,
владелец/продукт, digest неизменяемого запроса, manifest SHA256 и SHA256
каждого сохранённого этапа. Сценарий, три первоначальных рисунка и все MP3
копируются в частный cache нового задания. Старые region-планы не копируются:
разметка создаётся для окончательных изображений.

В этом режиме TTS программно запрещён. Нет вызова модели сценария;
основной автор отвечает только за выбор замечаний. Если MP3 отсутствует,
повреждён или не совпадает с сохранённым SHA, процесс останавливается до
генерации новых материалов. Голос и исходные реплики неизменны. Renderer
измеряет фактическую длительность исходных MP3 и строит раскрытие рисунков
по этим окнам; озвучка не ускоряется и не обрезается. Обычное кодирование
звуковой дорожки MP4 сохраняется, это не новая TTS-генерация.

Разрешена одна визуальная переделка на исходное задание; повторное нажатие,
включая закрытое или ошибочное задание, возвращает ту же задачу без нового
платного запуска. Цепочка переделок не допускается. История показывает
замечания и решения автора, сохранение звука, стадии проверки/перерисовки,
использование исходной озвучки и прогресс. JSON результата и offline re-render
сохраняют review/decision и SHA оригинальных/окончательных рисунков.

## Счётчики

Для нового ролика с тремя сценами по две реплики: базовые 13 вызовов
(сценарий1 + рисунки3 + разметки3 + MP3×6), критик1 + автор0–1 + перерисовки0–3,
итого максимум18. Форма выбирает один проход и лимит19 по умолчанию.
API без флага visual_review сохраняет отсутствие критика, но новый запрос всегда фиксирует Gemini/ClaudeHub; существующие одобрения и cache
не переписываются. Policy one_pass_v1 входит в новый fingerprint.

Переделка готового ролика: 0 новых сценариев, 0 новых первичных рисунков,
0 TTS; критик1 + автор0–1 + перерисовки0–3 + разметки3 = максимум8 новых
вызовов. Счётчик исходного задания наследуется, не обнуляется. Требуется
остаток не менее8 в ранее подтверждённом общем лимите. Для исходного ролика
34ff3a5e-be3f-448d-913e-4f66518506bf это 16+8=24, в пределах25,
если текущий счётчик и материалы останутся как в последней проверке.
Ни лимит API-вызовов, ни эта формула не являются денежной оценкой.

## Проверки и границы

Локальные проверки до установки: 95 passed за 9.88 с. В них используются заглушки
провайдеров и синтетическое аудио/изображения. Покрыты один batch review,
решающее слово автора, запрет minor/style/uncertain, максимум3 перерисовки,
учёт вызовов, отмена, cache replay без вызовов, реальный тестовый MP4,
offline re-render с исправленной картинкой, неповторяемый failed review,
одобрение и изоляция продукта. В визуальной переделке все6 MP3 совпадают
побайтно с исходными; вызываемые storyboard/TTS-заглушки намеренно падают,
подтверждая отсутствие обращения к ним. Corrupt audio блокирует весь запуск.

Это проверка поведения программы, не доказательство качества реальной
критической модели или новых рисунков. Сохраняется human_review_required;
не сообщать «все визуальные ошибки исправлены» без просмотра результата.
Ранее собранный реальный ролик имеет замечания владельца к содержанию
рисунков; успешный decode и полное раскрытие не означают фактическую точность.

Эта первоначальная контрольная точка относилась к разработке до установки.

## Закреплённый image API

ClaudeHub GET /v1/models вернул HTTP200 и ID gemini-3.1-flash-image.
Официальная документация:
https://app.claudehub.fun/docs/api/endpoints/images-generations
Новый адаптер отправляет только model/prompt/size на
https://api.claudehub.fun/v1/images/generations, с существующим ClaudeHub-ключом.
Автоматических fallback/retry на другой endpoint, модель или провайдера нет.
Портретный PNG дополняется белым полем до точного 9:16 без обрезки или
искажения геометрии. Провайдер и модель входят в неизменяемое одобрение
и cache fingerprint. При импортировании старых PNG/MP3 сохраняется provenance
исходного задания и его модели; старые PNG не выдаются за вновь созданные Gemini.

Число существенных замечаний не ограничено тремя или двенадцатью.
Технические ограничения размера JSON и числа output-токенов сохраняются.
Максимум3 перерисовки относится к трём сценам, а не к числу замечаний.
Дополнительные проверки покрывают официальный ClaudeHub endpoint, принудительную
модель/провайдера, отсутствие fallback при502, сохранение пикселей при padding
и read-only readiness: image catalogue ClaudeHub, voice/vision OpenRouter.
