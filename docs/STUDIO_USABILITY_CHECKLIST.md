# Проверка понятности Growth Studio

Цель: любой человек без опыта за минуту понимает, **что это за место, что здесь можно делать и что нажать дальше**.
Проверять после каждого заметного изменения интерфейса и перед выкладкой на growth.servgo.ru.

## 1. Автоматически (каждый раз, ~10 секунд)

```bash
python -m pytest -q tests/test_content_studio*.py
```

Тесты `test_content_studio_usability.py` следят, чтобы: ссылка на почту (mail.servgo.ru) была на каждой странице и открывалась в новой вкладке; в текстах не было внутренних слов («слоты», «артефакты»); меню «Ещё инструменты» не уходило за экран; кнопки были не меньше 44 px.

## 2. На телефоне (перед выкладкой, ~5 минут)

```bash
pip install playwright && playwright install chromium
python scripts/studio_mobile_audit.py https://growth.servgo.ru/studio/products/<ID> --user <логин> --password <пароль>
```

Скрипт открывает 11 разделов в ширине 360 px и сообщает: есть ли горизонтальная прокрутка, элементы за краем экрана, кнопки меньше 40 px.
Ожидаемый результат: у каждой страницы `OK`.

## 3. «Тест пяти секунд» (раз в неделю на свежем человеке)

Покажите главную страницу на 5 секунд и уберите экран. Спросите:
1. Что это за место?
2. Что здесь можно сделать?
3. Куда бы вы нажали первым?

Не смогли ответить на 1–2 вопроса — главная перегружена или непонятно подписана.

## 4. Задания для непродвинутого человека (не подсказывать!)

| Задание | Успех |
|---|---|
| «Создайте материал на любую тему» | нашёл «Создать материал» за ≤10 сек |
| «Узнайте, готов ли материал» | пришёл в «В работе» или «Готово» |
| «Скопируйте готовый текст» | открыл материал и нажал «Копировать» |
| «Откройте почту» | нашёл значок ✉ / «Почта» |
| «Найдите календарь публикаций» | открыл «Ещё инструменты» → «Календарь» |

Фиксируйте, где человек замешкался дольше 10 секунд: это место переписывать.

## 5. Чек-лист по каждому экрану

- [ ] Заголовок говорит, что это за раздел, обычным словом.
- [ ] Видно одно главное действие (одна яркая кнопка).
- [ ] Нет слов «слот», «артефакт», «пайплайн», «оркестратор» и сокращений («публикац.»).
- [ ] Пустой раздел объясняет, **почему** пусто и что сделать.
- [ ] Статус («В очереди», «Создаётся») понятен без пояснений.
- [ ] Ошибка написана по-русски, говорит что делать, не показывает код.
- [ ] Шрифт читается без увеличения (≥ 12 px, основной текст ≥ 14 px).
- [ ] Кнопки и ссылки не меньше 44×44 px, между соседними есть зазор.
- [ ] Нет горизонтальной прокрутки, ничего не обрезано по краям.
- [ ] Меню и выпадающие списки целиком помещаются на экран 360 px.
- [ ] Страница работает при крупном шрифте в настройках телефона (200 %).
- [ ] Всё доступно без мыши: Tab доходит до каждой кнопки, фокус виден.
- [ ] Текст и фон достаточно контрастны (серый на белом читается).

## 6. Что не является ошибкой сайта

Плавающие круглые кнопки у края экрана (например, с карандашом) — это элементы браузера или телефона. Их можно отключить в настройках браузера/клавиатуры; на странице их нет в коде.
