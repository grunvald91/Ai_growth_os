## Причина скрытых рисунков

Оплаченная разметка выбирала преимущественно подписи, пропуская части иконок.
Renderer раскрывал полный исходник при окончании сцены, но цикл в этот момент
уже переключался на следующую. Поэтому первые две полные сцены не попадали
в кадры. Код теперь раскрывает весь холст в последнем бите и гарантирует
полный последний кадр перед переходом. Для текущего видео дополнительно
использована ручная разметка полного заголовка и левой/правой половин.

перезагрузка VM 155.212.162.47; VMmanager подтвердил её 13 октября в 13:05
по Москве. Перед ней SSH и HTTPS зависали; консоль показала OOM kill и
ошибки systemd-служб. Конкретный процесс, вызвавший исходную перегрузку,
не установлен. После перезагрузки SSH восстановился, свободно около 11.7 GiB,
последняя нагрузка 0.96/1.02/0.74. Долговременная стабильность этим не доказана.

Обновлены только API и worker поверх существующих образов:
`servgo-pilot-api:ef0bbcb98528`, `servgo-pilot-worker:ef0bbcb98528`.
Оба запущены, локальный health HTTP200. Общий .env не изменился,
миграции БД не выполнялись, предыдущие образы и конфигурации сохранены.
[Исходный код](https://github.com/grunvald91/Ai_growth_os/commit/ef0bbcb98528ddbae6ebbb80a20d234b62052427).

Первый build не прошёл из-за интерпретации image ID как удалённого имени;

## Интерфейс и проверки

Развёрнуты история «Ваши анимации», русские статусы, read-only обновление
списка каждые 8 секунд, прогресс этапов и сведения об остановившемся этапе,
плеер с WebVTT, скачивание MP4/SRT/PNG/JSON. Форма сохраняет введённый текст
при ошибке. Профиль FLUX.2 Pro + Qwen3 VL + Grok/Eve (ru) выбирается в форме
и связывается с неизменяемым одобрением только одного задания.
Общие модели, голос, ключи и прокси не менялись.

На сервере в отдельном ASGI QA-процессе с production БД, файлами и settings
проверены: страницы HTTP200, SHA скачанного MP4 совпадает, attachment,
Range HTTP206/32 байта, SRT/VTT/PNG/JSON HTTP200.
В этом временном QA-процессе только зависимость владельца заменена заглушкой;
production-служба и её авторизация не менялись. Это не проверка реального
ввода пароля или авторизованного браузерного HTTPS-сеанса.

Правильный Origin https://growth.servgo.ru и некорректное короткое поле:
HTTP422 с сохранением текста; чужой Origin: HTTP403.
Политика CSRF сохранена. Конкретные старые коды ошибок
f4c323c5ef21 / 7bf029881d59 не сопоставлены с сохранёнными edge-журналами.
Read-only preflight выбранного профиля с существующими ключами/прокси:
ready=true, code=ready, платных генераций при проверке не было.

Реальный HTTPS с проверкой сертификата: страница видео HTTP401 без входа
(обычная защита Studio), servgo.ru HTTP200. Внешний /health возвращает404;
локальный API /health200. Авторизованный просмотр облачным браузером
не подтверждён; ссылки предназначены для обычного входа владельца Studio.
