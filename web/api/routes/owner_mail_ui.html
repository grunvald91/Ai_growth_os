Добавить компанию

Укажи адрес компании и имеющиеся сведения. Агент подготовит индивидуальный черновик.

Загрузить адреса

Вставь email по одному на строке (до 100). Можно также добавить название, HTTPS-сайт и заметку через точку с запятой. Подготовка писем — отдельное действие.

Новое письмо

Введите email, подготовьте текст самостоятельно или с ИИ. Сохранять адрес в контактах не обязательно.

Исходящий адрес ServGo не настроен на сервере — отправка будет отклонена. Нужна переменная SERVGO_MAIL_FROM.
