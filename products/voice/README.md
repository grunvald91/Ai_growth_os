# Словари голосового ввода

`global_dictionary.json` — общий словарь для всех проектов. Словарь конкретного проекта кладётся в
`products/<проект>/voice_dictionary.json` и перекрывает общий при совпадении слова.

Формат записи: `term` — как писать правильно; `heard_as` — как это обычно распознаётся (по звучанию);
`note` — короткое пояснение для модели; `hint: true` — слово попадает в подсказку распознавателю при каждом вызове
(для самых важных, их немного).

Сюда идёт только то, что не секретно: файл публичный.
